# 🍚 शालेय पोषण आहार (PM POSHAN) उपयोगिता नोंदवही व धान्य हिशोब प्रणाली

शाळांसाठी प्रधानमंत्री पोषण शक्ती निर्माण योजना (MDM) अंतर्गत मासिक व वार्षिक उपयोगिता प्रमाणपत्र आणि धान्य साठा नोंदवही भरण्यासाठीचे संपूर्ण ॲप्लिकेशन.

---

## 🚀 ॲप कसे सुरू करावे? (How to Run)
1. **एक क्लिकवर सुरू करा**: फोल्डरमधील `Start_App.bat` या फाईलवर डबल-क्लिक करा.
2. किंवा कमांड प्रॉम्प्टमध्ये:
   ```bash
   npm run dev
   ```
3. ब्राउझरमध्ये उघडा: **http://localhost:3000**

---

## 🌟 मुख्य वैशिष्ट्ये (Features)

1. **शाळेचे नाव व सेटिंग्ज (School Name & Settings)**:
   - शाळेचे नाव, केंद्र, तालुका, जिल्हा, UDISE कोड व इंधन खर्च दर (डीफॉल्ट ₹२.५९) बदलता येतो.
   - हे नाव एक्सेल डाऊनलोड व प्रिंट रिपोर्टच्या शीर्षस्थानी आपोआप येते.

2. **अनेक शैक्षणिक वर्षे (Multi-Year Support)**:
   - ड्रॉपडाउनमधून कोणतेही शैक्षणिक वर्ष (उदा. २०२४-२५, २०२५-२६, २०२६-२७) निवडा.
   - **+ नवीन वर्ष** बटणावर क्लिक करून नवीन वर्ष जोडता येते.
   - **Auto Carry-Forward**: मागील वर्षाची अंतिम ३१ मार्चची शिल्लक नवीन वर्षाच्या १ एप्रिल रोजी आपोआप सुरुवातीची शिल्लक म्हणून पुढे आणली जाते!

3. **धान्य सूची (Grain Menu List)**:
   - सर्व १७ धान्ये/घटक (तांदूळ, मुगडाळ, तुरडाळ, मसूरडाळ, मटकी, मुग, चवळी, हरभरा, वाटणा, जिरे, मोहरी, हळद, मिरची पावडर, तेल, मीठ, कांदा लसून, सोयावडी).
   - हवे असल्यास नवीन धान्य जोडण्याची, नाव बदलण्याची किंवा काढण्याची सोय.

4. **१ एप्रिल शिल्लक नोंद (Opening Stock)**:
   - वर्षाच्या सुरुवातीला शाळेकडे शिल्लक असलेले धान्य एकदाच भरण्यासाठी सोपा तक्ता.

5. **पटसंख्या, कार्यदिवस व ताटांची संख्या (Monthly Metrics)**:
   - सर्व ११ महिन्यांचे (एप्रिल ते मार्च) पटसंख्या, कार्यदिवस आणि प्रत्यक्ष लाभार्थी ताटांची संख्या.
   - इंधन खर्च (@ ₹२.५९ प्रति ताट) दरमहा व वार्षिक आपोआप निघतो.

6. **महिनानिहाय धान्य नोंद (Monthly Entry)**:
   - वरून महिना निवडा.
   - मागील शिल्लक आपोआप दिसेल (Lock).
   - तुम्ही फक्त **'प्राप्त'** आणि **'अखेर शिल्लक'** भरा.
   - **'शिजवलेले धान्य' आपोआप निघेल**:
     $$\text{शिजवलेले} = (\text{मागील शिल्लक} + \text{प्राप्त}) - \text{अखेर शिल्लक}$$
   - हीच शिल्लक पुढच्या महिन्यासाठी आपोआप सुरुवातीची शिल्लक बनेल.

7. **वार्षिक गोषवारा व एक्सेल डाऊनलोड (Annual Master Sheet & Download)**:
   - तुमच्या मूळ एक्सेल रचनेनुसार हुबेहूब संपूर्ण वर्षाचा मास्टर ताळेबंद तक्ता.
   - **Excel डाऊनलोड (.xlsx)**: एका क्लिकवर तुमच्या मूळ एक्सेल फाईलच्या फॉरमॅटमध्ये (`.xlsx`) डाऊनलोड होते.
   - **Excel इम्पोर्ट**: तुमच्या संगणकावरील जुनी एक्सेल फाईल अपलोड करून डेटा त्वरित लोड करा.
   - **प्रिंट / PDF**: पंचायत समिती/केंद्रप्रमुखांना सादर करण्यासाठी स्वच्छ प्रिंट फॉरमॅट.
   - **डेटा सुरक्षितता**: इंटरनेट नसले तरी सर्व डेटा तुमच्या ब्राउझरमध्ये कायम सेव्ह राहतो (Local Auto-Save).
